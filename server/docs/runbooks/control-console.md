# 中台控制台运行说明

## 访问

控制面服务启动后，控制台同源地址为：

`http://219服务器地址:3010/console/`

在部署环境中使用实际的服务器地址访问控制台。请仅向受信任的网络开放控制面。

## 登录与安全

首次打开页面输入管理员令牌。令牌不会写入静态前端包或数据库，只保存在浏览器 `sessionStorage`；关闭会话或点击“退出”即清除。

## 使用方式

1. 在顶部“输入需求信号”区域填写自然语言目标；可勾选“完成后由人工确认验收”。如需补充本任务资料，点击“附加本任务资料”选择一个或多个文件；它们在提交时被上传并冻结，只对本任务可见。
2. 提交后，任务列表自动选中该任务。执行区通过 SSE 实时接收需求接收、中台意图分析、智能体编排、智能体工作和结果验收等活动；右上角显示“实时连接”的当前状态。短暂断线后会自动申请新票据并补齐遗漏活动。
3. “智能体执行详情”逐节点显示：中台选择该节点的理由、能力类型、是否使用 Codex 运行时、状态、时长、证据摘要或当前进度。多轮检索、PPT 生成和质量验收会作为独立节点出现。
4. “资料、产物与质量结果”先展示任务冻结的资料及下载入口，再展示已验证工件、质量结论和资料不足等风险。选择人工验收的任务会在 `awaiting_review` 状态显示“确认验收”按钮。
5. “实时执行时间线”用中文展示每一步的来源、时间、与上一步的间隔以及关键关联信息。"开发者调试信息"默认折叠，需要排障时再打开查看任务活动、原始智能体事件、尝试记录和结构化节点结果。
6. 左侧“待审批智能体”可批准符合项目规则的新版本；批准后由节点管理服务执行自检。

资料上传、curl 调用、数据库字段和节点授权规则见 [任务私有资料运行手册](task-private-inputs.md)。

## 当前范围

控制台显示真实的持久化任务状态，而不在前端拼装流程。提交任务后，中台会读取审批后处于 `ready` 的智能体能力目录，调用本机 Codex 产生受 Schema 约束的结构化计划，再由协议编译器验证能力、输入、依赖、绑定和路径安全。通过验证后，调度器才会拉起多个独立智能体实例。

因此，对“制作 438c 项目介绍 PPT”这类需求，正确的计划可包含并行的知识库检索节点、依赖这些证据的 PPT 制作节点，以及最后的质量验收节点；实际节点取决于当时已经审核并就绪的能力和 Codex 的受限规划输出。控制台只展示这些实际编排的结果，不能替代计划器或绕过审批。

## 部署

```bash
cd /home/middleground/.worktrees/control-plane-ragflow-v1
corepack pnpm run console:build
systemctl restart mg-control-plane.service
```

在更新依赖后运行 `corepack pnpm install --frozen-lockfile`，然后再构建。
# 控制台交付物与人工返工

任务详情的“交付产物”区只显示已通过中台 SHA-256 校验并归档的文件。点击“下载”会以当前管理员身份请求 `/v1/tasks/:taskId/artifacts/:artifactId`；浏览器会保存文件，管理员令牌不会出现在地址栏。JSON、Markdown 与文本文件可点“查看内容”，以转义文本形式预览。

当质量验收未通过时，任务状态为“待人工验收”。管理员可选择：

- **确认当前交付**：接受现有版本；
- **根据质检意见返工**：保留现有版本，将上一版 PPT、质量报告、验收标准和失败摘要交给新的 PPT 尝试，再重新执行质量验收。

返工不会重新执行已经完成的知识检索节点。每次返工都会在 SSE 时间线中留下人工决定与新的智能体启动记录；历史版本仍可从交付产物区下载。

返工开始后，上一版 PPT、质量报告和验收标准只会以 `input/previous-*` 资料的形式保留；节点工作目录中的旧执行输出会先被清理。若 Codex 没有生成新的 PPT 或质量文件，界面会显示该智能体节点失败，不会把旧文件显示为“返工完成”。遇到这种失败时，展开“开发者调试信息”查看本轮 Codex 输出和节点错误，再决定修复智能体能力或重新发起返工。
