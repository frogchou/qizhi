# 互联网资料收集智能体

能力名：`research.web`。它通过公开网页检索接口收集资料，为每条结果保留 URL、摘要和标题，并在任务目录输出 `web-research.md`。返回结果中的证据字段可供中台、质量管理智能体和人工继续核验。

## 边界与验收

- 只检索公开互联网资料；不使用企业密钥、账号或登录态。
- 每一条结论性材料必须保留来源 URL；未找到来源不会伪造内容。
- 公开资料本身不等于事实确认，结果固定携带 `public_web_sources_require_fact_check` 风险。
- 自检只检查运行时的网络 API 能力，不发起任何外部请求。

## 独立实例协议

启动时共享运行时只从 `MG_TASK_ENVELOPE_PATH` 读取受控信封，验证节点目录仍在任务根目录内。它把 `web-research.md` 与协议结果留在节点目录，并以当前租约回调中台；公开来源不足时仍会交付风险，而不是伪造结论。
