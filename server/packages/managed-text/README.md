# 可在栖知中创建的文本智能体

生产线的创建操作接受名称、稳定标识、版本、能力说明和工作指令。后台把这些声明和输入输出 Schema 写进智能体包目录。每个版本使用自己的目录，自动发现只登记声明，管理员审批后才检查 Codex CLI 并加入启动清单。升级沿用同一标识、登记更高版本，旧版本仍可单独下线。也可以选择服务器上已部署的自定义智能体包登记。

模板的能力名为 `enterprise.<标识>.write`，标识中的连字符映射为下划线。接收必填字段 `brief`，返回字符串 `text` 和可下载的 `report.md`。运行时使用服务端的 Codex 和任务节点工作目录，按文本综合模式处理已提供的信息，实时回报运行状态。模板不授予额外工具；需要专门工具或不同 Schema 的智能体按既有包规范开发，部署新的版本目录后由管理员登记审批。下线阻止后续启动，已在执行的实例按原计划结束。
# 参考材料

新发布的模板声明可选数组 `referenceMaterials`。规划器使用 `taskInputBindings` 传递本任务明确授予的文件，也可使用 `inputBindings` 接收调度器从上游制品或证据生成的节点本地文件。文本运行时读取节点 input 目录内的普通文件，验证任务资料的授权与 SHA-256，再将 UTF-8 正文以 JSON 数据传给 Codex。单节点资料总量上限为 192 KiB，支持 Markdown、文本、CSV、JSON、YAML、XML 和 HTML 等类型。遇到二进制、不适用的文件类型或超限会报告失败。旧审核版本保留 brief-only 契约，接收文件绑定需要发布并审核支持 referenceMaterials 的新版本。
