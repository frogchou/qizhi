# 节点管理器

节点管理器与中台是独立进程，是第一期唯一能创建或停止智能体实例的服务。中台只发送逻辑身份、版本、工作目录和环境文件位置；节点管理器通过自己的已审核目录解析实际入口，不接受请求中提供的任意可执行路径。

每个实例使用确定性的 transient systemd 单元 `mg-agent-<instanceId>`。单元工作目录是该任务独立目录，停止请求针对同一单元名，因而可重试。第一期运行在已批准的 root 账号下；后续版本再将目录和系统账号隔离。

节点管理器只监听 `127.0.0.1`，其 `/internal/v1` API 使用独立的 `x-mg-internal-token` 令牌。服务环境文件只保存该令牌哈希，部署时由 root 以 `0600` 权限保存。
