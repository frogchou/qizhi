# 中台控制台

React/Vite 单页应用，由控制面同源提供在 `/console/`。浏览器首次访问需输入管理员令牌；令牌仅保存到 `sessionStorage`，关闭该浏览器会话后会自动删除。

功能：

- 输入自然语言需求信号，并在提交时选择平台自动验收或人工验收。
- 展示中台对需求的意图理解、经过编译校验的执行图、每个节点被选择的业务理由、运行时和状态。
- 通过任务范围固定的一次性 SSE 票据实时接收持久化活动；首次连接、断线重连和连接状态会在页面显示。重连会以最后活动编号补齐遗漏事件，而不会把管理员令牌放入 URL。
- 以中文时间线展示中台分析、编排、智能体启动、进度、结果和验收；规划阶段和 Codex 智能体均会显示 Codex 的存活、累计时长和最近输出新鲜度。流程总览会聚合所有节点，而非只取第一个节点。
- 运行中节点每秒显示实际执行时长；首次心跳前明确显示“中台正在等待首次心跳”，收到心跳后显示最近一次存活确认时间。Codex 节点额外显示子进程仍在运行、累计时长以及最近输出的新鲜度，避免把长任务误判为卡死。中台判定失联、停止实例和单次自动重试也会实时出现在时间线。
- “打开实时控制台”展示同一 SSE 活动流回放的统一执行事件，以及 Codex 等运行时上报的 stdout/stderr 片段；浏览器不轮询或伪造进度。
- 在“交付正文”中完整展示当前轮答复，并放在文件与质量验收之前；节点运行摘要继续用于执行诊断，不代替最终正文。Markdown 的标题、段落、列表、表格、引用、代码和安全链接以可读格式展示，原始 HTML 只作为转义文本显示。
- 优先读取任务详情的 `delivery` 投影：按 `answers` 展示正文，按 `artifactIds` / `supportingArtifactIds` 区分交付文件与过程留档。明确返回的空交付保持为空，不回退到旧节点结果或上一轮文件。旧接口仅从当前修订的计划恢复内容，依次采用完整 `answer` / `text`、可读的结构化分析发现与核验依据、摘要；等待新计划的修订不会重新展示旧结果。
- 保留证据来源、质量结论和风险；原始节点 JSON 仅在“开发者调试信息”中按需展开。质检生成的验收标准、评估 JSON 和上游参考文件默认收在“过程报告与参考文件”中，仍可预览、下载；文件扩展名不会单独决定分类，用户要求的 JSON 产物正常展示。
- 批准待审核智能体版本；在任务处于 `awaiting_review` 时确认当前交付，或在质量失败时明确发起“根据质检意见返工”。
- 在“交付产物”区下载经中台 SHA-256 校验且已归档的版本化文件；JSON、Markdown、TXT 可在控制台内以转义文本预览。下载和预览都使用管理员认证请求，不在链接中暴露令牌。

控制台不会自行生成流程，也不会伪造状态。它只读取控制面已经持久化的规划、调度、回调和验收结果。

调试区中的尝试记录经过 API 投影，不包含租约令牌；智能体协议事件和统一执行事件分开显示，便于区分“智能体真实上报”与“中台/节点管理服务执行的监督动作”。

构建：在仓库根目录执行 `npm run console:build`。部署由 `mg-control-plane.service` 提供构建后的静态文件。
