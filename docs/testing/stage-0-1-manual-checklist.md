# 栖知阶段 0–1 手工验收

- [ ] 首次启动不要求网络连接，也不包含任何 OpenAI、JEV、RAGFlow 或 Codex 业务调用。
- [ ] 在设置中输入连接信息后，重启应用仍只显示掩码；检查应用数据库不含 API Key。
- [ ] 尝试添加 Windows、Program Files、AppData、回收站、UNC 或重解析点作为扫描根目录，均被拒绝。
- [ ] 未安装或未启动 Everything 时，今日页仍使用内置 NTFS 索引；不出现递归扫描文件夹的提示。
- [ ] 安装程序以管理员权限完成本地索引服务安装后，设置页显示“索引服务已连接”。
- [ ] 添加一个允许的工作目录后，首次建立索引并确认今日列表只显示该目录中当天变化的文件元信息。
- [ ] 修改排除目录或文件类型后刷新，确认被排除目录、二进制文件和未选文件类型立即从今日列表隐藏。
- [ ] 选择一条今日文件后，使用“在资源管理器中定位”，确认定位到同一文件；移动文件后再次操作应安全失败。
- [ ] “加入知识库（后续版本）”和“生成今日总结”均不可用，不会上传或分析文件内容。
- [ ] 退出后检查发布目录、日志和设置导出中没有密钥、文件内容或未脱敏路径。
