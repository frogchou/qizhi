# 栖知 Mac 快速查找验收

测试环境为 Apple M4、macOS 27.2.1、本机 APFS。测试使用原生 Tauri 调试安装包和独立应用数据目录，文件均为自动生成的样本。

| 项目 | 实测 |
| --- | ---: |
| 固定文件清单 | 100,000 条，磁盘路径和索引逐条一致 |
| 首次建库 | 35.92 秒 |
| 查找后端 P95 | 8.05 毫秒，104 次 |
| 原生窗口键入到首屏 P95 | 133 毫秒，108 次，含 45 毫秒防抖 |
| 单文件新增到后端查找可见 P95 | 571.77 毫秒，50 次 |
| 单文件新增到原生窗口显示 P95 | 1.14 秒，50 次 |
| 重启后离线新增文件可查 | 152 毫秒，本轮单次实测 |
| 索引磁盘占用 | 416.16 MiB，不含文件本身 |

单字 `合`、双字 `合同` 和名称片段 `report` 各命中 100,000 条，扩展名 `.pdf` 命中 50,000 条。首屏样本覆盖中文单字和双字、扩展名、英文和中英文路径片段、稀疏命中及无结果。加载更多、过期响应、同名替换、Unicode 等价形式和权限变化由本机用例覆盖。

以相同机型和十万文件验收时，首次建库门槛定为 60 秒以内。不同磁盘、路径长度和目录数量会影响建库耗时与索引大小。首屏目标为 P95 不超过 150 毫秒，单文件变动到可查的目标为 P95 不超过 3 秒。

原生窗口测速保留了一个约 40 秒的样本。当时文件已进入界面树，窗口重新激活后才完成绘制采样。该样本纳入 P95 计算。

可在 Mac 上运行 `cargo test --locked --manifest-path apps/desktop/src-tauri/Cargo.toml --test macos_file_search_test measures_real_search_rebuild_and_incremental_updates -- --ignored --nocapture`，复测十万文件的后端查找、索引恢复和单文件变更。窗口首屏耗时由原生窗口单独采样。
