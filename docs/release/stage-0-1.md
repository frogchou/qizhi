# 栖知阶段 0–1 发布说明

版本：`0.1.0`

本阶段交付 Windows 本地优先的产品基础：安全设置、Windows 凭据管理器密钥存储、SQLite 元数据存储、Everything 可用性提示、今日文件工作台与资源管理器定位。发布物为 NSIS Windows 安装程序。

未交付：OpenAI/JEV 分析、RAGFlow 上传或问答、Codex 任务执行、浏览历史聚合、自动知识库写入。安装包不会内置任何端点或凭据。

安装后，在“设置”中由用户自行输入服务地址和密钥；密钥仅写入 Windows 凭据管理器。只有在用户添加允许的工作目录且 Everything 已运行后，才允许刷新本地文件元数据。

发布前按 [手工验收清单](../testing/stage-0-1-manual-checklist.md) 执行，并归档仅含通过/失败状态的记录。
