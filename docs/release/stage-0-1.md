# 栖知阶段 0–1 发布说明

版本：`0.1.0`

本阶段交付 Windows 本地优先的产品基础：安全设置、Windows 凭据管理器密钥存储、SQLite 元数据存储、内置 NTFS/USN 索引服务、今日文件工作台、RAGFlow 知识库问答与本机 Codex 项目工作空间。发布物为 NSIS Windows 安装程序。

当前版本支持 OpenAI 今日总结、JEV 价值评估、RAGFlow 检索/Agents 问答与文件上传，以及把“今日/过去”文件、知识库片段、知识库原文和 Agent 最终回答交给指定 Codex 项目会话。Codex 生成物可在用户确认目标知识库、目录和解析选项后上传 RAGFlow。浏览历史聚合和无人确认的自动知识库写入仍未交付。安装包不会内置任何端点或凭据。

安装后，在“设置”中由用户自行输入服务地址和密钥；密钥仅写入 Windows 凭据管理器。安装程序会注册受限的本地 NTFS 索引服务；用户添加允许的工作目录后，今日页通过服务同步元数据，无需 Everything。

“Codex 工作”复用本机已经安装并登录的 Codex，不要求在栖知中再次登录。跨页面发送资料时会先在目标项目中建立安全快照，再切换到对应会话；远端任务启动失败不会消费待用资料。生成物上传前会重新校验项目边界和内容哈希，上传结果不确定时不会自动重试。

发布前按 [手工验收清单](../testing/stage-0-1-manual-checklist.md) 执行，并归档仅含通过/失败状态的记录。
