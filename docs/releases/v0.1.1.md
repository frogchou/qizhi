# 栖知 v0.1.1

本版本完善了本地文件发现、图片资料处理和模型服务配置，并继续保持本地优先的工作方式。

## 主要更新

- “今日 / 过去”新增图片类型发现与筛选，可将受支持图片上传到 RAGFlow 知识库。
- 新增统一模型服务设置，支持 OpenAI、DeepSeek、千问、Moonshot、智谱、MiniMax、Ollama 和自定义 OpenAI 兼容服务。
- 同一时间仅启用一个模型服务；原 OpenAI 配置会自动迁移，今日总结自动使用当前启用的模型。
- 兼容 Responses API 与 Chat Completions API；Ollama 可在不填写 API Key 的情况下使用。
- 侧边栏显示实际应用版本号，设置界面和模型切换交互进一步优化。
- GitHub Actions 升级至 Node.js 24 运行时，消除 Node.js 20 弃用警告。

## 安全与升级

- API Key 继续保存在 Windows 凭据管理器中，不写入项目数据库或安装包。
- 从 v0.1.0 升级时会自动执行数据库迁移并保留原有配置。
- 安装程序采用 Windows x64、按计算机安装模式，安装本地 NTFS 索引服务时会请求 UAC 权限。

## English summary

Qizhi v0.1.1 adds image discovery and RAGFlow image upload, introduces a single-active-provider model service layer for OpenAI, DeepSeek, Qwen, Moonshot, Zhipu, MiniMax, Ollama and custom OpenAI-compatible endpoints, migrates existing OpenAI settings automatically, and updates GitHub Actions to the Node.js 24 runtime.
