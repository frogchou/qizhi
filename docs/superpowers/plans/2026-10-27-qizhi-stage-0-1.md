# 栖知阶段 0–1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Windows-first Tauri foundation and a usable, privacy-first 今日 experience that discovers files with Everything and reveals them in Explorer.

**Architecture:** React/TypeScript renders the approved app shell and calls typed Tauri commands only. Rust owns configuration, Windows Credential Manager access, SQLite, scan policy, Everything adapters and Explorer integration; all local/external capabilities sit behind ports with fakes for tests.

**Tech Stack:** Tauri 2, Rust, React, TypeScript strict, Vite, pnpm workspace, SQLite/rusqlite, `keyring`, Everything SDK IPC with `es.exe` fallback, Vitest, Rust tests, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-27-qizhi-desktop-design.md`

## Global Constraints

- Windows 10/11 x64 only; current delivery ends at stages 0–1.
- Do not implement or invoke OpenAI/JEV/RAGFlow/Codex business operations in this delivery.
- Never place API keys, document contents, or raw sensitive paths in source, fixtures, logs, database rows, crash reports, or version control.
- Store secrets solely in Windows Credential Manager; SQLite stores only a credential reference plus masked status.
- Only scan explicit allowed roots; reject Windows, Program Files, AppData, Recycle Bin, UNC paths, reparse points and user exclusions.
- If Everything is unavailable, show remediation and never silently fall back to a broad filesystem crawl.
- Preserve the approved four primary navigation items: 今日、知识库、Codex 工作、设置; only 今日 and settings are functional in this release.
- Use pnpm workspace, strict TypeScript, versioned database migrations, format/lint/test gates, semantic versions and conventional commits.

## Review Focus

- A system, UNC, AppData or reparse-point path is added as a root: reject it before discovery. **Task 3.**
- Everything returns a vanished or still-changing file: skip it with a local reason. **Task 4.**
- SDK and `es.exe` are both unavailable: report recoverable unavailable state, never scan directories. **Task 3.**
- A key or endpoint reaches UI/database/logs/errors: expose only a mask/redacted form. **Task 2.**
- Same identity is returned twice or scan crosses midnight: persist once and query by local calendar day. **Task 4.**
