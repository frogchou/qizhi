# Codex 工作空间与设置界面优化设计

## 目的

让用户能够安全地整理 Codex 项目和会话，并统一发送资料弹窗、项目操作入口和扫描设置区的视觉与交互质量。

## 已确认方案

- 项目和会话通过统一的三点菜单提供“重命名”和“删除”。
- 删除采用安全删除：从当前工作空间隐藏，但保留历史、资料快照和生成物；运行中的任务不可删除。
- 删除后自动选择下一个可用项目或会话，并在删除前显示明确确认。
- 资料发送弹窗保留原生 `select` 的无障碍和键盘行为，通过统一容器、圆角、字体、边框和箭头改善样式。
- “保存扫描范围”放入独立底部操作区；目录聚合阈值使用紧凑、对齐良好的数字输入控件，避免遮挡。

## 非目标

- 本次不增加回收站或归档恢复界面。
- 不永久删除 Codex 项目目录、资料快照、会话历史或生成物。
- 不改变资料交接、Codex 执行和扫描规则的业务语义。

## 验收标准

- 用户可以删除项目和会话，确认后项目树立即更新，选择状态不会指向已删除条目。
- 运行中的项目或会话不会被删除，并显示可理解的提示。
- 今日页和知识库页的发送弹窗使用一致且清晰的项目/会话选择控件。
- 项目操作按钮与弹出菜单在默认、悬停和键盘聚焦状态下均清晰可见。
- 设置页按钮、阈值输入框在当前桌面窗口宽度下无重叠、遮挡或异常尺寸。
- 相关前端测试、类型检查、格式检查和后端测试通过。
