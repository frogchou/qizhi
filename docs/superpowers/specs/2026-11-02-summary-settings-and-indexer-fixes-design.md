# 今日总结设置与索引服务修复设计

## 目标

- 修复电脑重启后本地 NTFS 索引服务停止、今日页显示“Windows 错误 2”的问题。
- 将“生成今日总结”改成视觉统一、尺寸稳定的分段下拉按钮。
- 将提示词管理从 OpenAI API 卡片中拆出，形成与模型供应商无关的独立设置区域。
- 取消提示词模板数量上限，支持持续新增、编辑、排序、设为默认和删除。

## 已确认方案

采用独立的“今日总结”设置区。顶部提供总结模型设置和新增/保存操作；下方使用紧凑的可展开列表展示提示词。每一行显示标题、默认标记和排序操作，点击后展开编辑标题与提示词。默认只展开当前编辑项，避免模板数量增加后页面过长。

## 行为与边界

- 提示词仍要求标题唯一、恰好一个默认项，单个标题最多 60 字，单个提示词最多 4000 字。
- 不再限制模板总数量；数据库和接口继续整组事务保存，保存失败不覆盖现有设置。
- OpenAI API 卡片只保留连接信息，不再承载提示词设置。现阶段总结模型字段仍使用已有 OpenAI 兼容调用，结构上预留未来模型来源选择。
- 总结按钮的主操作执行默认模板；右侧独立箭头打开模板菜单。两个区域共享高度、背景、圆角和禁用状态，不使用字体字符模拟箭头。
- NTFS 索引服务安装类型改为 Windows 自动启动；升级安装会更新已有服务配置并重启服务。当天确实没有文件时，服务返回正常空列表，不显示不可用错误。

## 验收

- 重启或重新安装后，`QizhiNtfsIndexer` 的启动类型为自动且服务运行。
- 今日文件为零时展示空状态，不出现 Windows 错误 2。
- 分段总结按钮在正常、悬停、禁用状态下边界连续且箭头居中。
- “今日总结”是设置页独立区块；OpenAI 卡片中不再出现提示词。
- 可创建超过 20 个提示词并成功保存、重新载入；大量模板默认保持紧凑列表形态。

## 非目标

- 本次不接入新的模型供应商，也不改变现有 OpenAI 总结协议。
- 本次不改变提示词文本长度和唯一性规则。
