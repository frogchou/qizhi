# 数据库

[中文](README.md) | [English](README_EN.md) | [Rust 核心](../../README.md)

该模块管理本地 SQLite 数据库、顺序迁移和领域仓储。数据包括文件元数据、配置状态、价值评估、总结提示词、Codex 项目/会话/资料/生成物以及交接记录。

迁移 14 新增资料筐。SQLite 记录资料名称、来源标识摘要、内容校验值、大小和时间。原始字节保存到应用数据目录的 `material-basket` 子目录，使用随机编号命名。完整写入后才登记项目。相同来源和内容去重，原件发生变化时可保存新快照。删除筐内资料不会删除已导入 Codex 项目的副本。工厂上传使用当前连接的凭据，临时本地附件仅在用户选择后读取。

密钥不写入 SQLite；这里只保存服务地址、非敏感设置和凭据是否存在等状态。所有架构变更必须增加不可重复执行出错的迁移测试。
