# 栖知智能工厂交互原型

## 演示基线

栖知的本地版本标签 `demo/factory-river-valley-v1` 保存河谷演示。演示入口在侧栏「智能工厂」，模拟工单由本目录的 `simulation.ts` 驱动。后续接入企业智能中台时保留可独立运行的模拟模式和工厂端到端用例；日常修改其他栖知功能时仍可从侧栏进入。

运行资源随栖知前端构建。地图使用 `river-valley.webp`，交通层使用 `worker.webp`、`van.webp`、`forklift.webp`。中台项目中的方案图、早期评审 HTML 和生成图片缓存只用于设计留档。演示工单不需要中台地址或令牌。资产仓的知识库按钮进入栖知已有的知识库页面，该页面使用栖知自己的服务配置。

若需对照原版，在栖知仓库根目录执行下列命令。第一条在新目录打开标签快照，当前开发目录可继续使用。新目录名应选尚未使用的路径。

```powershell
git worktree add --detach ../qizhi-factory-demo-v1 demo/factory-river-valley-v1
cd ../qizhi-factory-demo-v1
pnpm install --frozen-lockfile
pnpm --filter @qizhi/desktop dev
```

打开栖知后进入全厂总览。点状态数量筛选工单，点建筑查看区域队列，点工单或提交新需求后跟随。模拟自带工作中、资料连接阻塞、等待人工审批及已交付工单。可暂停、加速、重试、退回、批准、查看日志和交付单。默认模拟路线用于演示操作，运行于当前窗口内存，刷新重置，离开工厂或隐藏窗口暂停演示时钟。

## 画面与状态

建筑详情、状态筛选和工单详情共用地图右侧的浮层抽屉。抽屉独立滚动，打开和关闭时地图保持原尺寸；点关闭按钮、按 Esc 或点击地图空白处可收起。企业资产仓提供「打开栖知知识库」，通过主窗口导航进入当前知识库工作区。

river-valley.webp 是去除文字、按钮和光路的生态河谷底图。远山、桥梁、湿地、光伏车棚和厂房为静态场景。所有覆盖层共享 park-layout.ts 的 1833 × 858 坐标，地图按比例显示，抽屉独立覆盖。建筑热点显示模拟工单或资产，资产仓可跳转栖知知识库。

ValleyScene.tsx 的水纹仅在河面裁剪区域内平缓移动，随模拟暂停冻结，不随工作负载加速。中台屋顶全息图在规划时加强节点光效。ParkLights.tsx 绘制运行时与监控等设备读数。Traffic.tsx 用闭合路径与指数平滑控制人员、车流的速度。系统选择减少动态效果时保留静态状态。

任务、资料、算力和监控使用四种线路，运行时仅向中台和生产线供给。光点的速度取决于当前视图的执行工单数量与演示倍速。一次最多两条厂房动态，保留五个模拟秒，完整历史可在工单日志内查看。自动来单可在底部关闭；工单和心跳为前端模拟，尚未连接服务器。

## 验证

在 apps/desktop 运行 pnpm exec playwright test e2e/factory.spec.ts。浏览器验证覆盖自动交付、手动审批、返工、异常恢复、日志与侧栏切换。
