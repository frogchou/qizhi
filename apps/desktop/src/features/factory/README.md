# 栖知智能工厂

## 连接真实工厂

在栖知设置中的智能工厂连接页选择实时模式，填入中台地址和管理员令牌，测试并保存后从侧栏进入智能工厂。窗口顶部显示「中台实况」，底部显示连接状态和快照时间。连接中断时保留最近成功的快照并自动重连，未取得数据的建筑显示等待读取或错误。

- 需求接待大厅默认打开「需求列表」，展示所有渠道的工单。「接入情况」列出各渠道状态、工单数和最近接收时间。点击渠道跳回该渠道的需求列表，「查看所有渠道」清除筛选。使用左右方向键、Home 或 End 可切换页签。新需求记录桌面来源，提交成功后跟随服务端返回的工单。
- 智能体中台默认显示「进行中（全部在办）」，包含已接收、规划、执行、等候人工输入或验收以及正在停止的工单。「执行中」只显示执行状态。选择「全部状态」或「已验收」可查看历史。打开工单可查看各版计划、节点依赖、能力、绑定的智能体、执行尝试及引用依据。
- 智能体生产线打开「装配智能体」工作区。点击「管理智能体」可查看已上线、待审核、自检失败、已下线及删除中的版本，也可登记原有托管文本智能体或服务器安装包。关闭管理窗口后继续编辑原草稿。
- 质检中心默认显示「待质检」，汇总核验中和待人工验收的工单。可以单独筛选待人工验收、自动通过、失败、补查和返工。打开工单的质检页可查看验收轮次、缺项和依据，并对当前轮次操作。
- 企业资产仓显示本工厂配置的 RAGFlow 知识库目录、文档数、分块数及读取状态。可打开栖知已有的知识库工作区。
- 运行时支撑中心列出运行环境和执行实例，支持按环境、状态筛选。资源消耗按服务端采样展示累计 CPU 时间、内存和进程数。缺少数据时显示未采集。
- 运行监控中心可以按上报方和事件类型筛选，并跳转到关联工单时间线、实例和最近心跳。
- 成果交付中心展示通过验收的成果。可查看文字答复或选择归档文件，下载对应工单的具体修订。

在工单详情点击「停止工单」，核对需求和工单号后确认。中台会停止该单的规划和执行，取消待处理节点与输入请求。已结束工单保留历史和成果。进入「正在停止」的工单可重试相同请求。

悬停或通过键盘聚焦建筑可查看快照摘要。点击建筑打开独立滚动的浮层，使用关闭按钮、Esc 或地图空白处收起。工厂打开时使用全局变更游标订阅两类记录，即任务活动和智能体版本变更。网络恢复时重新读取快照，并刷新当前面板。实况线路、设备活动和短时提示使用中台记录。演示保留独立的模拟时钟与工单。

## 即时说明与运行时

术语右侧的 `ⓘ` 支持悬停、键盘聚焦和点击固定；固定后按 Esc 关闭。它用于解释当前对象，不会发起接口调用或改变工单状态。顶部「工厂说明」按运行时、执行流程、资料与交付、审核与操作归纳所有说明。 说明列表固定为单列，每项标题在上、解释在下；对应样式显式覆盖工厂通用双列详情布局，宽屏和窄屏都保留完整阅读宽度。

- 「本地服务运行时」表示服务器上的智能体程序直接调用企业接口、知识库、文件或固定工具，不启动大模型推理。
- 「Codex 推理运行时」表示智能体在本地服务中调用 Codex，用于理解、生成、研究和质量判断。
- 服务端出现未知运行时标识时，界面保留原始值并展示通用说明，不将其误判为本地服务或 Codex。
- 停止工单会终止未完成节点及等待输入，保留历史和已产生结果；停止后不能从停止点继续。下线版本只阻止新节点分配，已启动实例可完成。退回重制和补充需求会保留上一轮记录，并建立新一轮计划，而不是直接改写既有成果。

## 需求、附件和人工续办

在生产线的「工作说明」写下委托，交由装配助手整理并追问，或展开手工编辑填写稳定标识、主能力、版本、流程和验收条件。「资源与权限」显示中台实际可用的 Skill、具体 MCP 工具、业务能力，以及 RAGFlow 数据集名称、ID 和连接状态。可选择多个知识库。勾选后保存，所选 Skill 和工具以完整的 `id@version` 登记。新草稿的空知识库范围表示未获知识库授权。出现并发修订时，界面保留本地更改，可将手工编辑的字段合入最新修订，或采用中台版本。

「精选资源管理」支持填写或导入 Skill 的 Markdown 正文。每个版本可附带 16 个以内的辅助文件，原始大小合计最多 256 KiB。导入整个文件夹会保留相对路径，根目录的 SKILL.md 用作正文。保存前可核对或移除文件，查看已登记版本时可预览和下载附件。复制为新版本会保留原有正文和文件。MCP 资源可绑定中台已安装的工具，具体版本会显示参数、返回值、效果、目的地和模拟适配器。下架后不能再被新草稿选用，紧急停用还会阻止待执行调用。

在「候选与试跑」生成候选后，可核对封存摘要、源码和与上一版的差异。选定候选，填写样例需求并通过工厂现有上传入口添加一份或多份附件。工单详情支持按提问的字段答复、补交文件、停止执行、查看调用和工具回执以及下载工单制品。草稿保存关联的修订、候选和试跑工单号，重新打开后可接续。必需自动断言和样例验收条件满足后，由用户明确认可此次试跑，再将同一候选和工单提交发布审核。

「管理智能体」中的发布依据可追溯至已测的快照、源码、工单和产物。审核与自检通过后才上线。装配版本可复制为新版本草稿。删除此版本前会显示完整标识和版本，中台拒绝删除时可核对占用工单；「删除智能体（全部版本）」另外列出涉及的登记版本。部分节点撤销失败时可在删除中的版本上重试相应的操作。

普通需求可以直接提交，也可以展开「本次任务授权」，明确勾选主能力、可委托能力、MCP 工具及知识库。已上线装配候选支持将所需范围带入新需求。真实对外写入需要用户勾选并填写本单目的地。界面将目的地和需求一并送交中台。

新建需求可在「上传本地文件」中选择临时文件，或从「资料筐」勾选栖知中保存的今日文件、知识库片段和知识库原文。两种来源可以一起提交。临时文件直接暂存在当前工厂。资料筐条目在提交时上传快照，可在其他工单中再次选择。部分上传失败时可重新选择或移除失败项；成功项保留在表单中。完成后，可从工单的「任务编排 → 本单冻结的输入资料」核对名称与来源。

处于待人工验收的工单可在「质检验收」中确认、退回重制或补充需求。退回重制可写明修改意见。补充需求至少包含一段文字或一份附件，也可同时提交。每次提交都会记录在原工单下，创建新的规划与验收轮次。历史计划、历轮验收、修订记录和归档制品都可在同一工单中查看。平台按服务端规定对上传暂存设置有效期；若超过期限，本地附件需要重新选择，资料筐可重新发送已保存的快照。

## 阅读和下载成果

工单的「交付成果」先展示本次修订的完整分析正文。Markdown 标题、段落、列表和代码按阅读格式显示，纯文本保留原样；「复制完整成果」复制完整正文，不使用验收摘要的截短版本。分析两份文件时，可直接阅读每份文件的结论与建议。

交付文件紧随正文，保留具体制品的下载和校验信息。验收标准、质量评估等过程文件收在默认折叠的「执行与质检记录」中。文件归类以中台的交付清单为准，用户要求的 JSON 等文件仍可作为正式成果下载。新修订规划期间不显示上一次的成果；历史内容仍可从计划和验收记录查看。

较旧中台未返回交付清单时，客户端只读取当前计划与当前修订，优先使用节点完整答复和分析明细，再兼容验收文字与摘要。Markdown 中的原始 HTML 不执行，外部来源链接在新窗口打开。

## 演示基线

栖知的本地版本标签 `demo/factory-river-valley-v1` 保存河谷演示。在设置选择演示模式后，入口在侧栏「智能工厂」，模拟工单由本目录的 `simulation.ts` 驱动。项目保留可独立运行的模拟模式和工厂端到端用例；日常修改其他栖知功能时仍可从侧栏进入。

运行资源随栖知前端构建。地图使用 `river-valley.webp`，交通层使用 `worker.webp`、`van.webp`、`forklift.webp`。中台项目中的方案图、早期评审 HTML 和生成图片缓存只用于设计留档。演示工单不需要中台地址或令牌。资产仓的知识库按钮进入栖知已有的知识库页面，该页面使用栖知自己的服务配置。

若需对照原版，在栖知仓库根目录执行下列命令。第一条在新目录打开标签快照，当前开发目录可继续使用。新目录名应选尚未使用的路径。

```powershell
git worktree add --detach ../qizhi-factory-demo-v1 demo/factory-river-valley-v1
cd ../qizhi-factory-demo-v1
pnpm install --frozen-lockfile
pnpm --filter @qizhi/desktop dev -- --host 127.0.0.1
```

打开栖知后进入全厂总览。点状态数量筛选工单，点建筑查看区域队列，点工单或提交新需求后跟随。模拟自带工作中、资料连接阻塞、等待人工审批及已交付工单。可暂停、加速、重试、退回、批准、查看日志和交付单。默认模拟路线用于演示操作，运行于当前窗口内存，刷新重置，离开工厂或隐藏窗口暂停演示时钟。

## 演示画面与状态

建筑详情、状态筛选和工单详情共用地图右侧的浮层抽屉。抽屉独立滚动，打开和关闭时地图保持原尺寸；点关闭按钮、按 Esc 或点击地图空白处可收起。企业资产仓提供「打开栖知知识库」，通过主窗口导航进入当前知识库工作区。

river-valley.webp 是去除文字、按钮和光路的生态河谷底图。远山、桥梁、湿地、光伏车棚和厂房为静态场景。所有覆盖层共享 park-layout.ts 的 1833 × 858 坐标，地图按比例显示，抽屉独立覆盖。建筑热点显示模拟工单或资产，资产仓可跳转栖知知识库。

ValleyScene.tsx 的水纹仅在河面裁剪区域内平缓移动，随模拟暂停冻结，不随工作负载加速。中台屋顶全息图在规划时加强节点光效。ParkLights.tsx 绘制运行时与监控等设备读数。Traffic.tsx 用闭合路径与指数平滑控制人员、车流的速度。系统选择减少动态效果时保留静态状态。

任务、资料、算力和监控使用四种线路，运行时仅向中台和生产线供给。光点的速度取决于当前视图的执行工单数量与演示倍速。一次最多两条厂房动态，保留五个模拟秒，完整历史可在工单日志内查看。自动来单可在底部关闭；演示模式的工单和心跳在前端生成。

## 验证

装配草稿、选项和快照操作位于 `/v1/factory/assemblies`，资源版本位于 `/v1/factory/assembly-resources`。草稿保存、澄清和生成携带中台修订号，澄清、生成、试跑和发布还携带可重试的请求编号。试跑接受和发布分别绑定 `runId` 与 `candidateId`。正式工单在开启自定义范围时提交 `authorizedCapabilities`、`authorizedDatasetIds` 和 `authorizedMcpTools`。按版本撤销使用 `POST /v1/factory/agents/:agentId/versions/:version/delete`。桌面桥接和浏览器开发代理均按方法及具体路径校验请求。

在 apps/desktop 运行 `pnpm exec playwright test e2e/factory.spec.ts e2e/factory-live.spec.ts`。演示用例显式选择演示模式。实况用例通过测试用的桌面命令响应验证八栋建筑、真实轮次和制品编号、版本操作及断线恢复。
