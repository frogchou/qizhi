# 资料筐

侧栏底部的「资料筐」工具可在任意页面打开。资料保存在当前桌面安装中，可多选本地文件、批量移除或确认清空。资料筐分列展示文件名、来源和快照大小，同一来源标签只显示一次。相同来源的重复加入由原生服务去重，并按项报告加入、已存在或失败。移除筐内条目后，已经交给工单或会话的快照仍由各自的任务保管。

- 今日和近期文件使用当前目录查询的文件、目录标识。知识库片段和原文件使用本轮查询的选择令牌。原件由桌面服务获取。
- `MaterialBasketSelector` 的 `selectedIds` / `onChange` 控制一个表单的选择；打开选择器不会自动传送任何资料。若当前选择已从筐中移除，界面显示失效条目并允许移除。该组件可以嵌入工厂需求和验收补充表单。传入 `compact` 可使用紧凑工具栏，`leadingAction` 可在同一行放置上传按钮。展开时，材料列表占据下一行。
- Codex 会话的「从资料筐添加」把所选快照绑定到当前项目、会话和下一次发送。资料加入成功后可在「本轮资料」查看或移除，编辑中的消息保持原样。
- 浏览器预览缺少本机资料服务时显示桌面端提示。真实持久化、读取和会话绑定通过 `QizhiCommands` 及本机命令完成。

`MaterialBasket.test.tsx` 和 `MaterialBasketFlows.test.tsx` 覆盖跨页管理、失效选择、文件和知识库来源以及会话材料随下一条真实发送调用传递。
