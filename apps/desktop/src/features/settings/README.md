# 设置

[中文](README.md) | [English](README_EN.md) | [功能模块](../README.md)

该模块集中管理扫描与隐私规则、OpenAI 兼容服务、JEV、RAGFlow、Codex 偏好和今日总结提示词。

设置页的二级分类包括“扫描与隐私”“连接服务”“价值评估”“今日总结”“Codex 工作”和“智能工厂”。右侧一次显示当前分类。所有面板保持挂载，切换分类会保留尚未保存的输入。宽窗口使用左侧分类栏，窄窗口使用顶部横向分类栏。

- `SettingsPage.tsx`：分类导航、设置草稿状态、连接测试和扫描目录选择。
- `SummarySettingsSection.tsx`：可增删的总结提示词与默认模板。
- `CodexSettingsSection.tsx`：Codex CLI 状态、模型和推理强度。
- `FactorySettingsSection.tsx` 管理演示与实时模式、控制面地址、管理员令牌及连接测试。旧版安装首次进入时使用演示模式。实时模式由桌面端从 Windows 凭据管理器读取令牌，地址变更需要输入对应令牌。测试连接会读取实际工厂总览，设置在点击保存后生效。

智能工厂的运行模式使用并排的单选项，可以用方向键切换。地址和令牌沿用全局字段样式，连接测试与保存放在表单底部。窄窗口中标签位于字段上方。

在“设置 → 智能工厂”中选择“实时工厂”，填写控制面根地址和管理员令牌，点击“测试工厂连接”及“保存工厂设置”。受信任内网可使用 `http://192.168.2.219:3010`。桌面端使用系统文件选择器保存服务端交付物。

实时工厂通过同一连接查询智能体使用状态、删除整个智能体身份或停止指定工单。正在使用的智能体须先等待关联工单结束或停止相关工单。遇到阻止操作的状态，请在工厂刷新并查看服务器结果。

需要在浏览器开发预览接入时，将 `QIZHI_FACTORY_DEV_ORIGIN` 设为指定控制面的根地址，运行 `pnpm dev --host 127.0.0.1`，在设置中输入令牌。预览代理只接受本机访问并固定目标地址。刷新或关闭页面会清除连接和令牌。

密钥输入仅用于写入 Windows 凭据管理器，重新读取设置时只返回掩码状态。目录通过系统选择器添加，保存后应给出明确反馈并立即影响“今日”查询。
